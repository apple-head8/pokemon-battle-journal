# 対戦ノート

`start.cmd` をダブルクリックすると起動します。Node.js が必要です。
画面: http://127.0.0.1:4318

- サーバーは背景で起動します。PC再起動後は同じ `start.cmd` で再開できます。
- 保存先: `data/battles.json`。直前の保存状態は `data/battles.json.bak` に残ります。
- バックアップボタンで全対戦のJSON、CSV出力で絞り込み中の対戦を出力できます。
- JSON読み込みは追加方式。同じIDの記録は上書きしません。
- 勝率は勝ち数÷記録数（引き分けを含む）。積む機会の集計は「作れた」「作れなかった」の回答のみ対象です。
- 入力途中の内容は同じブラウザの下書きに保存。確定した記録はPCのファイルに保存します。
- 外部公開やクラウド同期は行いません。履歴はこのフォルダ内のファイルです。
- 構築名は自由入力。技・配分を変更したら名前を変えて比較してください。
- 過去11戦は構築・選出に不明な点があるため、自動で登録していません。

テスト: `node --test server.test.js`

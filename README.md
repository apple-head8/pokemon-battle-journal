# ロトムログ

**対戦を記録して、次の一手を見つける。**

ポケモンチャンピオンズのパーティーと対戦の流れを残せる、非公式の対戦ノートです。特定のポケモンや構築に限定せず使えます。アカウント登録・AIのAPIキーは不要です。

記録は自分の端末に保存します。対応するPCブラウザなら、普段の「保存」で指定したJSONファイルを更新できます。そのファイルを好きなAIに添付して、選出や立ち回りを振り返ることもできます。

**[Web版を開く](https://apple-head8.github.io/pokemon-battle-journal/)**

## できること

- **パーティー管理**：6匹の名前・特性・持ち物・性格・能力ポイント・技を登録。複製、並び替え、没にする・復帰に対応。
- **入力補助**：性格の上昇補正を赤、下降補正を青で表示。能力ポイントは各32、合計66まで。
- **対戦記録**：相手の6匹、双方の選出、ターンごとの行動、勝敗、振り返りを記録。ターン番号は自動で付きます。
- **履歴と集計**：構築や勝敗で絞り込み、勝率などを確認。履歴のCSV出力にも対応。
- **当時の型を保持**：対戦の保存時点のパーティーを記録するため、後から型を変えても過去の対戦を振り返れます。
- **ライト・ダークモード**：使いやすい表示に切り替えられます。

ポケモン名や技などは手入力です。図鑑データの自動補完や、技・特性の使用可否判定、ダメージ計算はありません。

## はじめ方

**PCの最新Chrome・Edgeを推奨します。** ファイルへの直接保存には、ブラウザの対応と利用者の許可が必要です。

1. 初回画面で「新しく始める」を選び、記録用のJSONファイルを作ります。以前の記録がある場合は「記録ファイルから再開」で開きます。
2. パーティー管理画面で6匹を登録します。
3. 対戦画面で構築を選び、対戦内容を入力して保存します。
4. 履歴画面で振り返ります。AIに相談したいときは、保存したJSONを添付します。

**パーティーと対戦履歴は1つのファイルにまとまります。試合ごとにファイルを作る必要はありません。** 次回は同じブラウザで開くと保存先の設定を読み込みます。再度許可を求められた場合は、初回画面の案内に従ってください。

ファイルへの直接保存に未対応の環境では「ブラウザ保存で始める」を利用できます。この場合、ブラウザデータの削除で記録が消えるため、保存設定の「詳細操作」から定期的にJSONをダウンロードしてください。スマートフォンでは直接保存を前提としないでください。

## 保存設定と復旧

画面上部の「保存設定」から変更できます。

| 操作 | 動作 |
| --- | --- |
| 別の記録ファイルを開く | 選んだファイルの記録に切り替えます。現在の記録とは統合しません |
| 今の記録を別ファイルに保存 | 現在の記録を引き継ぎ、以後の保存先も変更します（詳細操作内） |
| 復旧用JSONをダウンロード | ブラウザに保持している記録のコピーを出力します。保存先は変更しません（詳細操作内） |
| 許可して再保存 | 書き込みに失敗した変更を、許可を確認して保存し直します |

- 保存エラーが出た場合は、画面を閉じたりブラウザデータを削除したりせず、保存設定を確認してください。ファイルへ書けなかった変更はブラウザに退避します。
- 外部からファイルが変更された場合や、古いタブから保存した場合は、上書きを止めます。複数のブラウザ・アプリで同時編集しないでください。
- 「保存」前の入力途中の内容はJSONに含まれません。ファイルへの上書き保存は、過去の版を残すバックアップではありません。
- 端末やブラウザを変えるときは、JSONを移して開いてください。自動同期はありません。
- ローカル版・試用URLから公開URLへ設定は自動移行しません。公開URLで保存済みのJSONを開き直してください。

## AIに相談する

ロトムログからAIへ自動送信することはありません。利用するAIサービスのデータの扱いを確認し、必要な内容だけ共有してください。たとえばJSONとともに、次のように依頼できます。

```text
添付はポケモン対戦の記録です。直近10戦の負け筋を整理してください。
記録にある事実と推測を分け、選出・初手・積むタイミングを検討してください。
構築変更案は、現在の役割を失う点も含めて比較してください。
記録が不足していて判断できない部分は、その旨を明記してください。
```

## データとプライバシー

アプリは対戦記録をサーバーに送信せず、アクセス解析や広告も組み込んでいません。ファイルに加えて、復旧用の記録や設定をブラウザ内に保持します。保存内容は暗号化されません。配信サービスには、ページへのアクセス情報が記録される場合があります。

ブラウザ保存だけでの長期保管や、端末故障・ファイル削除からの復旧は保証できません。重要な記録は別の場所にもコピーを保管してください。詳細は[公開・保存設計](battle-log/WEB-RELEASE.md)を参照してください。

## 自分のPCで動かす・開発する

Node.js 24とnpmを推奨します。

```sh
git clone https://github.com/apple-head8/pokemon-battle-journal.git
cd pokemon-battle-journal/battle-log
npm ci
npm run build:web
npm test
npm run preview:web
```

プレビューは <http://127.0.0.1:4319/> です。

従来のローカル版は `npm run build` → `npm start` で <http://127.0.0.1:4318/> に起動し、`battle-log/data/battles.json` へ保存します。Windowsでは `battle-log/start.cmd` も利用できます。ローカル保存APIをインターネットへ公開しないでください。

技術構成と変更手順は[開発ガイド](battle-log/README.md)、GitHub Pagesへの配布手順は[公開ガイド](battle-log/WEB-RELEASE.md)を参照してください。
